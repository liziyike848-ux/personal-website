# Zhiyuan Shen · 个人主页

以文字为主的个人网站，采用米色纸面、书刊式章节和固定顶部导航。

## 当前功能

- 六个章节：开篇、关于我、我的经历、我的思考、日常片段、联系我。
- 每个章节至少占满一屏，使用虚线分隔。
- 阅读进度条、章节跳转与当前章节高亮。
- 可展开的经历记录、文章阅读弹窗。
- 方块按钮及悬浮变色效果，支持手机布局与减少动态效果的系统设置。

实习、文章和日常内容中标注“待补充”或“草稿”的部分尚未完成。

## 文件

- `index.html`：页面内容。
- `styles.css`：样式与响应式布局。
- `app.js`：阅读进度、章节高亮和弹窗交互。

网站无需构建，也没有外部运行依赖。

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 8765
```

打开 <http://127.0.0.1:8765/>。

此仓库用于保存网站代码。GitHub Pages 尚未配置。
